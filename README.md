# Онлайн-школа — Frontend

Клиентская часть веб-приложения для учёта кружков. Реализована на **JavaScript** со сборщиком **Vite**, взаимодействует с бэкендом на **ASP.NET** через REST API.

> Групповой проект. В рамках командной разработки я реализовывала роль «Кладовщик».

---

## О проекте

Система предназначена для ведения учёта кружков и поддерживает разделение прав доступа по двум ролям — **работник** и **кладовщик**.

### Возможности роли «Работник»

- управление интересами и подбор к ним материалов;
- создание занятий и связывание их с интересами;
- создание достижений и привязка их к занятиям;
- получение списков материалов по выбранным занятиям в формате текстового документа или электронной таблицы;
- получение отчётов по интересам с расшифровкой по кружкам и достижениям за период — на почту или в программе.

### Возможности роли «Кладовщик»

- формирование списка проводимых кружков и необходимых для них материалов;
- создание медалек школьникам за успешную работу на кружках;
- связывание кружков и занятий, привязка материалов к кружкам и медалек к материалам;
- получение списков занятий по выбранным материалам в формате текстового документа или электронной таблицы;
- получение отчётов по кружкам с расшифровкой по интересам и медалькам за период — на почту или в программе.

## Технологический стек

- **JavaScript** — язык разработки;
- **Vite** — сборщик и dev-сервер;
- **Bootstrap 5 + Bootstrap Icons** — стилизация и иконки;
- **Axios** — HTTP-клиент для работы с REST API (ASP.NET);
- **ESLint + Prettier** — линтинг и форматирование кода.

## Запуск проекта

### Требования

- Node.js (LTS-версия)
- npm
- Запущенный бэкенд (ASP.NET) — репозиторий: [ссылка на бэкенд](#)

### Установка и запуск в режиме разработки

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Anitonchik/CourseWork_School_Front.git
cd CourseWork_School_Front

# 2. Установить зависимости
npm install

# 3. Запустить dev-сервер Vite
npm start
```

Vite поднимет dev-сервер (по умолчанию `http://localhost:5173`) с горячей перезагрузкой.

### Сборка и запуск production-версии

```bash
# Собрать проект (результат в папке dist/)
npm run build

# Собрать и сразу запустить на http://localhost:5173
npm run prod
```

Либо отдельно:

```bash
npm run build   # сборка в dist/
npm run serve   # раздача dist/ через http-server на порту 5173
```

### Линтинг

```bash
npm run lint
```

## Скрипты

| Команда         | Действие                                        |
|-----------------|-------------------------------------------------|
| `npm start`     | запуск dev-сервера Vite                         |
| `npm run build` | сборка production-версии в `dist/`              |
| `npm run serve` | раздача `dist/` через http-server на порту 5173 |
| `npm run prod`  | сборка + раздача (`build` + `serve`)            |
| `npm run lint`  | проверка кода ESLint                            |
