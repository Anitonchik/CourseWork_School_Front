# Онлайн-школа — Frontend

Клиентская часть веб-приложения для учёта кружков. Реализована на **JavaScript** и взаимодействует с бэкендом на **ASP.NET** через REST API.

> Групповой проект. В рамках командной разработки я реализовывала роль **«Кладовщик»**.

---

## О проекте

Система предназначена для ведения учёта кружков и поддерживает разделение прав доступа по двум ролям — **работник** и **кладовщик**.

### Возможности роли «Работник»
- управление интересами и подбор к ним материалов;
- создание занятий и связывание их с интересами;
- создание достижений и привязка их к занятиям;
- получение списков материалов по выбранным занятиям в формате текстового документа или электронной таблицы;
- получение отчётов по интересам с расшифровкой по кружкам и достижениям за период — на почту или в программе.

### Возможности роли «Кладовщик»
- формирование списка проводимых кружков и необходимых для них материалов;
- создание медалек школьникам за успешную работу на кружках;
- связывание кружков и занятий, привязка материалов к кружкам и медалек к материалам;
- получение списков занятий по выбранным материалам в формате текстового документа или электронной таблицы;
- получение отчётов по кружкам с расшифровкой по интересам и медалькам за период — на почту или в программе.

## Запуск проекта

### Требования
- Node.js (LTS-версия)
- npm
- Запущенный бэкенд (ASP.NET) — репозиторий: [ссылка на бэкенд](https://github.com/Anitonchik/CourseWork_School)

### Установка и запуск

# 1. Клонировать репозиторий
git clone https://github.com/Anitonchik/CourseWork_School_Front
cd CourseWork_School_Front

# 2. Установить зависимости
npm install

# 3. Запустить в режиме разработки
npm start
